# Fluent UI System Icons

Microsoft's Fluent UI System Icons, version 1.1.345: 2,988 icons drawn at sizes from 10 to 48 px in regular, filled and, for some, colour and light styles, 20,775 SVG files in total. Brand logos are left out.

Packaged by HorizonX · Version 1.0.1 · November 2026

## What's inside

- `svg/<size>/`: one folder per drawing size (10, 12, 16, 20, 24, 28, 32 and 48 px).
- File names carry the size and style, for example `svg/24/home_24_regular.svg` and `svg/24/home_24_filled.svg`.
- 2,471 icons at 24 px regular; 196 have a full-colour `_color` version.
- `LICENSE.txt`: the Fluent UI System Icons MIT licence, which must travel with the icons.
- Format: SVG; regular and filled icons are single-colour shapes, colour icons keep their own gradients.

## How to use them

- **Websites and apps:** paste the SVG inline or load it as an image. For regular and filled icons, set `fill="currentColor"` on the `<svg>` element to take the text colour of the parent.
- **Pick the size folder:** each size is drawn for that pixel size, so use the 20 px file at 20 px instead of shrinking the 24 px one.
- **Design tools:** Figma, Illustrator, Sketch and Affinity open SVG directly. Drag a file onto the canvas.

## Tips

- Regular for resting states, filled for selected states: the pair shares the same name.
- The colour icons work well as feature or empty-state illustrations at 32 or 48 px.
- Microsoft's `@fluentui/react-icons` package ships the same drawings as React components.
